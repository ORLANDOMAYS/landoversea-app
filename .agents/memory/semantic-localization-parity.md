---
name: Semantic localization parity
description: Why structural locale coverage is insufficient after material product or policy copy changes.
---

Translation completeness requires both structural key parity and semantic value parity. After adding or materially changing user-facing flows, disclosures, or policies, verify that every supported locale conveys the current meaning rather than merely defining the same keys.

**Why:** A locale coverage suite can remain fully green when new English text has been copied into non-English dictionaries or when old translations still describe obsolete behavior.

**How to apply:** Keep automated key coverage, then scan changed non-English values for copied source text and review policy/security-sensitive translations against the current English behavior before launch.
